# xl-reignsound

Redirect infrastructure for `xl.reignsound.com`.

## Purpose

This repository provides the deployment configuration used to redirect:

`https://xl.reignsound.com`

to:

`https://reignsoundrecords.github.io`

It is intentionally limited to routing and redirect infrastructure.

The `reignsound-xl` repository/project name is reserved for the Reignsound XL application and should not be conflated with this redirect repository.
